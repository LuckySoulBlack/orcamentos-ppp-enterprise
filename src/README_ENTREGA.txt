ORCAMENTOS PPP / OS PPP - CODIGO-FONTE

Este diretorio contem o codigo-fonte dos dois aplicativos:

- Orcamentos PPP: app principal administrativo.
- OS PPP: app operacional de ordens de servico.

Arquivos de entrada:
- app/main.py: inicializacao do Orcamentos PPP.
- app/main_os.py: inicializacao do OS PPP.

Executaveis gerados:
- Orcamentos_PPP.exe
- OS_PPP.exe

Instalacao final recomendada:
C:\Orcamentos_PPP

Pacote de entrega:
Pacote_Instalacao_Pendrive_Orcamentos_PPP_20260714

Regra importante:
- Para ajuste visual simples, pode atualizar apenas o EXE.
- Para tela nova, funcao nova, relatorio novo, dependencia nova ou banco alterado, atualize a pasta completa preservando o app.db real do cliente.

Consulte README_INSTALACAO_CLIENTE.txt na raiz do projeto antes de entregar para cliente.
